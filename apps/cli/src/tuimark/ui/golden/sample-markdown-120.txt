• the delay doubles on every attempt                                                                                    
• the last error is rethrown, see the MDN page (https://developer.mozilla.org/docs/Web/API/fetch)

• linear backoff is gone

2. count the attempts                                                                                                   
3. sleep 200 * attempt ms
